## gst folder

-\> copy the "gst" folfer in a ~/Documents/Ircam.
The resulting path is : ~/Documents/Ircam/gst

## description

-\> contains all extra files used save/recall user preset according to categories of process

-\> subfolder "scale-norm" contains default of examples of presets (files in json format) used to save/recall normalization values used by : gst.norm.multi and gst.norm.single
